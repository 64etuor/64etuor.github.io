llmwiki 패턴과 본 볼트의 정합성 점검

llmwiki 패턴과 본 볼트의 정합성 점검

원 질문: "llmwiki 관점에 맞춰서 우리 지침들은 어느 정도 수준으로 구현됐는지 확인해봐"

LLM Wiki (카파시) 의 3-layer 아키텍처와 3-op 운영 모델을 본 볼트의 시스템 파일들에 대조해 정합성·신선도·가동률을 점검한 결과를 보존한다.

카파시 spec 요약

LLM Wiki 패턴은 세 레이어(Raw sources → Wiki → Schema)와 세 연산(Ingest / Query / Lint)으로 구성된다. 컴파운딩의 핵심은 쿼리 답이 새 페이지로 환원되는 루프 — 이 노트 자체가 그 루프의 첫 발화다.

부속 인프라로 index.md(콘텐츠 카탈로그)와 log.md(## [YYYY-MM-DD] op | Subject 형식의 append-only 연산 이력)가 있다.

커버리지 매트릭스

구성요소 spec 본 볼트 구현 평가
Schema layer CLAUDE.md/AGENTS.md CLAUDE.md + 라우팅 테이블 + Pre-Flight 체크리스트 + tag-system / vault-map ★★★★★ spec 이상
Raw sources layer 불변 (immutable) Clippings/ + _assets/ + _papers/ + _external/. 4-28에 vault-map에 immutability rule 명문화 ★★★★
Wiki layer LLM 산출물 200_* ~ 900_* + type: literature/permanent 노트 ★★★★
Ingest op 1소스 → 10-15 페이지 갱신 process-clipping / process-book-note 7-step ★★★★★
Query op 답이 새 페이지로 환원 query-to-note 정의 + 이 노트가 첫 실행 ★★★ (가동 시작)
Lint op 모순·구식·고아·연결 부재 vault-maintenance Deep Lint 섹션 ★★★★
index.md 카테고리별 카탈로그, ingest마다 갱신 index 7.9KB, 4-28 신선도 회복 ★★★★
log.md append-only, 파서블 prefix log 동일 포맷, 6 엔트리 (ingest 2 / lint 2 / structure 2 / query 1=이 노트) ★★★★
Cross-reference 모순 플래그 inline wikilink 우선, > [!warning] Contradicts [[X]] 컨벤션 ★★★★★
자체 강화 (spec 외) MECE 태그(domain/source/action), Visual Aids 규칙, 파일명 특수문자 금지, 폴더 바운드 source 태그 ★★★★★

갭 분석에서 도출된 4-28 액션

원래 점검 직후 식별된 4가지 결함을 같은 날 처리:

  1. Raw 불변성 미명시 → vault-map에 "Raw Sources (immutability rule)" 섹션 신설. Clippings/·_assets/·_papers/·_external/을 immutable로 정의하고 가공은 별도 노트로 분기하는 규칙 명문화.
  2. index.md 신선도 → 4-17·4-22 변경(Harness Engineering 노트 이동, raw 폴더 4종 신설)이 21일 동안 index에 미반영이던 것을 회복. Harness Engineering 섹션 + Raw Asset Folders 섹션 추가.
  3. log.md 신선도 → 22일 공백을 4-28 lint 엔트리로 메움.
  4. 시스템 파일 한국어 비중 (토큰 비용) → CLAUDE.md, tag-system, vault-map, programs/4개 영문화. 한국어 비율 60%대 → 0~0.4%대.

검증

7개 운영성 테스트 통과:

  • log.md 파서블 (grep "^## \[" log.md)
  • 시스템 파일 한국어 0~0.4%
  • wikilink [[==]] 균형
  • index.md 신규 엔트리 5/5 실파일 존재
  • vault-map의 raw asset 폴더 5/5 실존
  • 라우팅 테이블 경로 → 실파일 매칭
  • Pre-Flight 10개 항목 (Visual Aids 포함)

발견·처리된 버그: tag-system 라인 38의 백틱 감싼 wikilink (자기 규칙 위반) → 백틱 제거.

결론

Schema·Raw·Wiki 3-layer 분리가 spec 이상으로 단단하고, Ingest·Lint는 가동 중. 4-28 작업으로 Raw 불변성·index 신선도·log 신선도·토큰 비용 4가지 결함이 동시 해소되고, 이 노트가 query op 첫 발화로서 컴파운딩 루프를 가동시켰다. 본 볼트는 카파시의 llmwiki 모델을 충실히 구현한 사례다.
