Tag Count Audit — 2026-05-04

CLAUDE.md tag rule: 3-8 tags per note (1-3 domain + 1 source + 0-1 action). This audit scans every in-scope .md and flags notes that fall outside the band, with focus on whether the minimum (≥1 domain + ≥1 source) is satisfied.

Summary

  • Total scanned: 1161
  • Compliant (3-8 tags): 827 (71.2%)
  • Under-tagged (0-2): 330
  • Over-tagged (9+): 4
  • Missing source-tag entirely: 114
  • No frontmatter at all: 13 (mostly Templates/ scaffolds — expected)

Of the 330 under-tagged notes, the dominant patterns are:

  1. Single-domain stubs without src/ — concept dictionary notes in 500_Resources/철학/, 500_Resources/심리학/, 500_Resources/UX 디자인/ (24+ files). They have one domain tag and nothing else.
  2. src/article only, no domain — clipping-derived tech notes in 600_Tech Stack/ that were saved with the source tag but never received a dev/* or ai/* domain (40+ files).
  3. System files — index.md, log.md, tag-system.md, vault-map.md, template-catalog.md carry only infra/obsidian. These are self-referential infrastructure; adding src/experience would make them compliant.
  4. Templates — all Templates/*.md scaffolds have empty or missing tag arrays, which is acceptable since they are template skeletons, not knowledge notes.
