UX 디자인

UX 디자인

UX 디자인 폴더는 사용자와 시스템이 만나는 인터페이스를 설계할 때 작동하는 핵심 원리들을 모아 놓은 공간이다. UX 디자인이란 무엇인가가 이 폴더 전체의 토대 노트로, 사용자 경험 디자인의 정의·목표·방법론적 기반을 개관한다. 여기에 담긴 개념들은 독립적으로 참조될 수도 있지만, 인지 부하를 줄이고 행동을 유도하며 결과를 평가하는 세 축이 맞물려 작동하는 통합된 설계 논리로 읽을 때 가장 강력하다.

구성 개념

  • UX 디자인이란 무엇인가 — 이 폴더 전체의 토대 노트. 사용자 경험 디자인의 정의·역사·방법론적 기반을 개관하고, 이하 개념들이 왜 하나의 체계를 이루는지를 설명한다.
  • 인지 부하 — 인터페이스와 상호작용할 때 작업 기억에 가해지는 정신적 부담. 내재적·외재적·생성적 부하를 구분하며, 설계로 줄일 수 있는 외재적 부하가 주요 타깃이다.
  • 멘탈 모델 — 사용자가 시스템 내부 동작에 대해 스스로 구축한 개념적 표상. 개념 모델과의 간극이 클수록 오류와 좌절이 커지며, 좋은 UX는 그 간극을 최소화한다.
  • 힉의 법칙 — 선택지 수가 늘수록 의사결정 시간이 대수적으로 증가한다는 원리. 메뉴 구조와 온보딩 설계에서 인지 부하를 제어하는 정량적 근거로 쓰인다.
  • 피츠의 법칙 — 목표물 크기와 거리가 조작 시간을 결정한다는 운동심리학 법칙. 버튼 크기·위치 배치에서 클릭 효율을 최적화하는 데 적용된다.
  • 어포던스 — 대상의 물리적·지각적 속성이 사용자에게 행위 가능성을 암시하는 관계적 속성. 깁슨의 생태심리학에서 출발해 노먼이 디자인 담론으로 이식했다.
  • 시그니파이어 — 어포던스가 존재함을 사용자에게 명시적으로 알리는 지각 단서. 어포던스는 속성이고 시그니파이어는 그것을 드러내는 신호라는 점에서 구별된다.
  • 제약 — 가능한 행동 범위를 좁혀 오용과 오류를 방지하는 설계 원리. 물리적·의미론적·논리적·문화적 제약으로 분류되며, 불필요한 선택을 차단해 인지 부하도 줄인다.
  • 피드백 — 사용자 행동에 대해 시스템이 전달하는 응답 신호. 즉각적이고 명확한 피드백은 멘탈 모델 형성을 돕고 오류 회복 비용을 낮춘다.
  • 맵핑 — 컨트롤과 그 효과 사이의 공간적·개념적 대응 관계. 자연스러운 맵핑은 별도의 학습 없이도 직관적 조작을 가능하게 한다.
  • 야콥의 법칙 — 사용자는 익숙한 패턴을 기대한다는 일관성 원칙. 혁신보다 관습 준수가 인지 효율을 높인다는 설계 결정의 근거로 쓰인다.
  • 휴리스틱 평가 — 닐슨의 10대 원칙을 기준으로 전문가가 인터페이스를 점검하는 저비용 사용성 감사 기법. 사용자 테스트의 전처리 필터로 산업 표준이 되었다.
  • 더블 다이아몬드 — 발견·정의·발전·전달의 발산-수렴 4단계로 UX 프로세스를 구조화하는 디자인 카운슬 프레임워크. 문제 정의와 해결책 생성을 각각 독립된 다이아몬드로 다룬다.

어떻게 포괄하는가

이 폴더의 개념들은 사용자-시스템 인터페이스를 지배하는 세 축을 따라 전체 지형을 구성한다. 첫째, 인지 축은 사용자의 작업 기억과 판단 속도를 다루며, 인지 부하가 설계로 줄일 수 있는 외재적 정신 부담의 총량을 정의하고, 멘탈 모델이 시스템의 실제 구현과 사용자의 내적 표상 사이의 간극을 분석하는 틀을 제공하며, 힉의 법칙과 피츠의 법칙이 각각 선택지 수와 목표물 크기·거리를 조작 시간의 정량적 함수로 환산하여 인지 비용을 설계 결정으로 직접 연결한다. 둘째, 행동유도성 축은 시스템이 어떻게 행동을 이끌어내는가를 다루며, 어포던스가 대상 속성과 행위 가능성 사이의 관계를 정의하고, 시그니파이어가 그 가능성을 사용자에게 드러내는 지각 단서 역할을 하며, 제약이 행동 범위를 좁혀 오류를 예방하고, 피드백이 행동 후 응답 신호로 멘탈 모델 보정을 돕고, 맵핑이 컨트롤과 효과 사이의 자연스러운 공간 대응으로 학습 비용을 줄인다. 셋째, 평가·프로세스 축은 설계가 올바르게 작동하는지를 점검하고 개선을 이끄는 방법론적 장치를 담으며, 휴리스틱 평가가 사용자 없이도 전문가 집단이 인터페이스를 저비용으로 감사하는 표준 기법을 제공하고, 야콥의 법칙이 관습 준수가 인지 효율을 높인다는 일관성 원칙으로 설계 결정을 안내하며, 더블 다이아몬드가 문제 정의와 해결책 생성을 각각 독립된 발산-수렴 단계로 구조화하여 프로세스 전체를 조율하는 메타 프레임워크로 기능한다. 이 세 축은 독립적으로 작동하지 않으며, 인지 비용을 낮추기 위해 행동유도성 설계가 최적화되고 그 결과가 평가·프로세스 축의 점검을 통해 피드백 루프를 완성한다는 점에서 하나의 통합된 설계 논리를 이룬다. UX 디자인이란 무엇인가는 이 세 축이 어떻게 사용자 경험이라는 단일 목표로 수렴하는지를 개관하는 출발점이다.
