시맨틱 웹

모든 웹 자원이 형식 의미로 기술되어 기계가 사람의 도움 없이 의미를 합성할 수 있도록 만들겠다던, 2001년 Tim Berners-Lee의 웹 차세대 비전.

정의

시맨틱 웹(Semantic Web)은 2001년 Tim Berners-Lee, James Hendler, Ora Lassila가 Scientific American 5월호에 발표한 「The Semantic Web」에서 정식화된 비전이다. 핵심 주장은 단순하다 — 웹 페이지가 사람에게 읽히는 문자열이 아니라, 기계가 의미를 따라가며 합성할 수 있는 데이터의 그래프가 되어야 한다. 이를 위해 모든 자원에 URI를 부여하고, 자원 사이의 관계를 RDF 트리플로 기술하며, 클래스 위계와 제약은 OWL(기술 논리 (Description Logic)에 기반)로 적는다는 기술 스택이 함께 제안되었다.

비전이 흥미로운 이유는 단순히 검색 품질의 개선이 아니라 웹 전체를 개념화의 명세로 덮자는 야망에 있었다는 점이다. 페이지가 의미를 적으면, 에이전트는 그 의미를 따라 추론할 수 있다는 약속이었다.

구조 / 작동 방식

시맨틱 웹의 표준 스택은 흔히 "Layer Cake"로 그려진다 — 아래에서 위로 URI / Unicode → XML → RDF / RDFS → OWL → SPARQL → 추론 / 신뢰 / 증명. 각 층은 다음 층의 약속 베이스가 된다.

층 역할
URI 모든 자원에 전역 식별자 부여
RDF (subject, predicate, object) 트리플로 사실 적기
RDFS / OWL 클래스·속성·제약을 형식 논리로 명세
SPARQL 그래프 위 질의 언어
추론 명시 사실에서 새 사실 도출

한계와 함의

웹 전체를 RDF로 덮자는 야망은 표상 비용 (Representation Cost)의 벽에 부딪혔다. 도메인 전문가가 OWL을 짜야 하고, 데이터 공급자가 그 모델에 맞춰 자료를 정렬해야 한다는 전제는 인터넷의 속도와 맞지 않았다. 살아남은 것은 야망의 부분 채택이다 — Schema.org가 검색 엔진을 위한 가벼운 마크업 어휘로 자리잡았고, Wikidata가 백과사전적 사실의 거대 그래프를 떠받쳤으며, JSON-LD가 OWL의 무게를 덜어낸 직렬화로 살아남았다.

LLM 시대의 시맨틱 웹은 비전이 아니라 골격으로 재배치되고 있다고 볼 수 있다. 전체 웹을 형식화하는 대신, 특정 도메인의 지식 그래프 (Knowledge Graph)가 LLM의 의미 부재를 보충하는 자리로 호명된다.
