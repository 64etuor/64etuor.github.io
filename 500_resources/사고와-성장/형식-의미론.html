형식 의미론

문장의 의미를 진리 조건과 모델 안에서의 충족 관계로 환원해 다루는, 기호 기반의 의미 이론.

정의

형식 의미론은 자연어 또는 인공 언어의 표현을 논리식으로 번역한 뒤, 그 식이 특정 모델(개체들의 집합 + 관계 + 해석 함수) 안에서 참이 되는 조건을 명시함으로써 "의미"를 규정한다고 보는 입장이다. 20세기 초 프레게와 타르스키의 작업에서 시작해 몬테규(Richard Montague)가 1970년대에 자연어로 확장했고, 이후 가능세계 의미론·유형 이론·기술 논리(Description Logic)로 분화되며 분석철학과 전산 언어학, 시맨틱 웹의 공통 기반이 되었다. 핵심 메커니즘은 합성성(compositionality) — 복합 표현의 의미는 부분 표현의 의미와 결합 규칙으로부터 기계적으로 계산된다고 본다.

구조 / 작동 방식

층위 역할 예
구문(syntax) 표현을 트리/형식으로 파싱 사람(소크라테스)
번역(translation) 표현을 논리식으로 매핑 ∀x. 사람(x) → 죽는다(x)
모델(model) 개체 도메인 + 술어 해석 함수 D = {소크라테스, 플라톤, ...}, 사람 = {소크라테스, ...}
충족(satisfaction) 모델에서 식의 참/거짓 판정 모든 사람이 죽는 모델에서 위 식은 참
추론(entailment) 전제 집합에서 새 식을 연역 "소크라테스는 사람이다" + 위 식 ⊢ "소크라테스는 죽는다"

분포 의미론이 단어를 고차원 벡터로 두고 코사인 유사도로 의미를 근사하는 것과 달리, 형식 의미론은 참값과 추론 규칙을 1차 시민으로 둔다. 그래서 같은 표현이라도 모델이 다르면 의미(참값)가 달라진다는 점이 명시적으로 드러난다.

예시

  • 시맨틱 웹의 OWL/RDF: 클래스·속성·개체를 기술 논리(Description Logic)로 정의하고, 추론 엔진(Pellet, HermiT)이 "이 환자는 당뇨병이다 → 이 환자는 만성질환자다"와 같은 함의를 기계적으로 도출한다. 의료·법률·금융 같은 감사 가능성이 요구되는 영역에서 여전히 쓰이는 경향이 있다.
  • LLM 환각 방지의 그라운딩 레이어: 에이전트가 도구를 선택하기 전에 도구의 전제·후행 조건을 형식 명세로 표현해 두면, 호출 가능 여부를 분포적 유사도가 아니라 충족 관계로 판정할 수 있다. 최근 AI 에이전트 스택에서 부분적으로 회귀하고 있는 흐름이다.

한계 / 흔한 오해

자연어의 모호성·은유·맥락 의존성을 형식화하려면 모델이 폭발적으로 복잡해지는 경향이 있어, 형식 의미론만으로 일상 언어 전체를 다루려는 시도는 1990년대 이후 대체로 후퇴했다. "형식 의미론 = 구식 GOFAI"라는 단순 등식도 오해다 — 현대에는 분포 의미론과 결합해 하이브리드 그라운딩(벡터 검색 + 기호 추론)으로 재배치되는 흐름이 강하다.
