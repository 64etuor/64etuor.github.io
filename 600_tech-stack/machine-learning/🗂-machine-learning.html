Machine Learning

Machine Learning

Machine Learning 폴더는 통계 기초·회귀와 모델 선택·분류와 클러스터링·평가·실험설계를 가로지르는 노트들을 모아 놓은 공간이다. 알고리즘 단편이 아니라 어떤 데이터에서 어떤 가정으로 무엇을 추정하고 어떻게 검증하는가라는 ML 워크플로 전체를 다섯 축으로 본다.

구성 개념

  • Bayes Theorem — 사전·우도·사후 확률의 정의와 의학 진단 Python 예제, ML·NLP·비즈니스 분석 응용. 베이지안 추론의 출발점.
  • Log-likelihood Function — 로그우도 정의·유도, MLE 최적화, 정규·베르누이 예제와 ML·베이지안 추론 응용.
  • ANOVA(Analysis of Variance) — 분산분석 개념, F-통계량·p-값 해석, 일원·이원·반복측정 변형, Python statsmodels 예제.
  • KDE(Kernel Density Estimation) — 커널 밀도 추정 개념, 가우시안 커널·대역폭 선택 원리, 히스토그램 대비, scipy 구현.
  • OLS(Ordinary Least Squares) — 최소제곱 회귀 설정, SSE 최소화, statsmodels 예제, R²·p-값·F-통계 해석과 가정 검증.
  • AIC (Akaike Information Criterion) — AIC 정의·공식·특성, BIC·Adjusted R² 비교, 회귀·GLM 모델 선택 워크플로.
  • Response Surface Methodology(반응표면방법론) — 반응표면방법론의 구조와 메커니즘 — 다항 회귀를 엔진으로 실험 표면을 모델링하고 최적점을 찾는다.
  • K-Means Clustering Algorithm — K-Means 메커니즘(반복적 중심 갱신), sklearn 예제, 강·약점, 고객 세분화·이상 탐지 응용.
  • DBSCAN(밀도 기반 클러스터링) — 밀도 기반 클러스터링 원리와 파라미터(eps, minPts), K-Means 대비. 노이즈 데이터의 클러스터링 선택 기준.
  • EBM(Explainable Boosting Machine) — Explainable Boosting Machine 개념과 특성, XGBoost 대비 해석가능성 우위.
  • ML 평가 - F1 Score와 ROC-AUC — F1과 ROC-AUC 개념·차이·적용 기준을 재현율-정밀도 trade-off로 본다. 분류 지표 선택 기준.
  • SMOTE — 불균형 데이터의 오버샘플링 기법 SMOTE의 작동 원리와 사용법. 불균형 분류 전처리 결정.
  • 앤드류 응의 머신러닝(7-1) 과적합 문제 — Andrew Ng 강의 7-1: 과적합 원인, 고편향 vs 고분산, 정규화 해법.
  • DOE(Design of Experiments) — 다수 인자를 동시에 변동시켜 주효과·교호작용·분산을 통계적으로 분리해 내는 실험설계 방법론.
  • OFAT(One Factor At a Time) — 전통적 일변량 실험 접근 — 직관적이지만 교호작용에 구조적으로 맹점.
  • 요인설계(Factorial Design) — 다수 인자를 모든 조합에 걸쳐 동시에 변동시켜 주효과와 교호작용을 분리 추정하는 실험설계.
  • Robust Design — 다구치 강건설계 — 노이즈 원인을 제거하는 대신 제품을 노이즈에 둔감하게 설계한다. 분산 축소·반취약성 논의.
  • EDA(Exploratory Data Analysis) — EDA 목표와 기술통계·시각화·결측치·이상치·상관 기법, pandas-seaborn 워크플로.
  • Scikit-learn Library — sklearn 공식 시작 레퍼런스: estimator, preprocessing, pipeline, 모델 평가 핵심 API.

어떻게 포괄하는가

Machine Learning 폴더의 노트들은 다섯 축을 따라 ML 워크플로의 전체 지형을 구성한다. 첫째, 확률·우도 기초 축은 모든 추정의 형식적 토대를 다루며, Bayes Theorem이 사전·우도·사후의 분해를 정의하고 Log-likelihood Function이 그 우도를 로그로 가져와 MLE라는 일반적 최적화 도구로 환원하며 ANOVA(Analysis of Variance)·KDE(Kernel Density Estimation)가 가설검정과 비모수 밀도 추정이라는 통계 기법을 같은 토대 위에서 사용 가능하게 만든다. 둘째, 회귀와 모델 선택 축은 어떤 모델을 어떤 데이터에 맞추고 어떻게 비교할 것인가를 다루며, OLS(Ordinary Least Squares)가 잔차 제곱합 최소화라는 가장 기초적인 회귀를, AIC (Akaike Information Criterion)이 잔차 적합도와 모델 복잡도를 정보이론으로 묶어 모델 선택의 균형 기준을 제공하고, Response Surface Methodology(반응표면방법론)이 회귀를 단순 예측 도구가 아니라 실험 표면을 모델링해 최적점을 찾는 엔진으로 끌어올린다. 셋째, 분류·클러스터링·평가 축은 라벨이 있는·없는 데이터를 다루는 두 갈래와 그 결과를 측정하는 도구를 묶으며, K-Means Clustering Algorithm·DBSCAN(밀도 기반 클러스터링)이 중심 기반과 밀도 기반이라는 두 클러스터링 접근의 가정 차이를 보여 주고, EBM(Explainable Boosting Machine)이 해석 가능성을 트레이드오프하지 않는 부스팅 대안을 제시하며, ML 평가 - F1 Score와 ROC-AUC이 재현율-정밀도 trade-off와 임곗값 독립 평가의 두 시각을 분리하고, SMOTE·앤드류 응의 머신러닝(7-1) 과적합 문제가 불균형과 과적합이라는 두 만성 실패 모드의 처방을 제공한다. 넷째, 실험설계 축은 데이터를 어떻게 수집할 것인가라는 가장 윗단 결정을 다루며, OFAT(One Factor At a Time)이 직관적 일변량 접근의 한계를 드러내고 DOE(Design of Experiments)·요인설계(Factorial Design)이 교호작용을 분리 가능한 형태로 데이터를 설계하는 패턴을 제공하며, Robust Design이 노이즈 제거가 아닌 노이즈 둔감화라는 다구치식 관점을 더해 분산 축소·반취약성 논의로 폴더를 다른 도메인과 연결한다. 다섯째, EDA·도구 축은 위 네 축이 실제로 코드 위에서 굴러가게 하는 실용 표면으로, EDA(Exploratory Data Analysis)가 모델링 이전의 데이터 이해 단계를 단단히 묶고 Scikit-learn Library가 estimator·preprocessing·pipeline·평가 API라는 공통 인터페이스로 위 모든 축을 실행 가능한 코드로 연결한다 — 도구 축이 없으면 다른 네 축은 개념의 묶음에 머물지만, EDA와 sklearn이 함께 놓이면 폴더는 작동하는 ML 워크플로의 카탈로그로 착지한다.
