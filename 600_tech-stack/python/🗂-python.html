Python

Python

Python 폴더는 비동기·동시성, 웹·네트워킹, 언어 기본기·내장 레퍼런스, 데이터·크롤링의 네 축을 가로지르는 노트들을 모아 놓은 공간이다. Python을 언어 한 층이 아니라 코루틴 모델 → 웹/네트워킹 라이브러리 → 데이터 워크플로가 같이 굴러가는 런타임 표면으로 보는 시야를 담는다.

구성 개념

  • python 코루틴(coroutine) - 동시성과 병렬성, 동기와 비동기 작업, blocking과 non-blocking 그리고 코루틴 (1) — 협동(cooperation)이 핵심인 코루틴 모델로 동시성/병렬성·동기/비동기·blocking/non-blocking을 통합 정리.
  • MissingGreenlet — SQLAlchemy async에서 가장 흔한 함정 — SQLAlchemy async의 MissingGreenlet 오류 근본 원인·greenlet 브리지 구조·6 트리거 시나리오와 해결 패턴.
  • FastAPI를 위한 Elasticsearch 대안 — 검색 엔진 선택 가이드 — FastAPI 통합 코드와 함께 Meilisearch·Typesense·PostgreSQL FTS·OpenSearch·Tantivy 비교.
  • OPC UA Server — python-opcua 라이브러리로 OPC UA 서버·클라이언트 구현, 보안 설정 포함.
  • Websockets — websockets 라이브러리로 실시간 서버·클라이언트 구현, 인증·스케일링 가이드.
  • Unpacking — 튜플 언패킹 개념과 for 루프 활용. Python 반복 패턴과 destructuring의 관용구.
  • 파이썬 내장 오류 목록 — Python 3.9 내장 예외 클래스 전체 표(설명·발생 조건·사용 문법).
  • 파이썬 내장 함수 목록 — Python 3.9 내장 함수 전체 표(formal name·설명·사용 문법).
  • 네이버 크롤링 난이도, 차단 방식, 해결법 — 네이버 서비스별 크롤링 난이도·봇 차단 방식·실무 우회·API 대안.
  • 파이썬을 통한 대규모 더미데이터 생성 방법 — e-commerce 예제와 Faker 라이브러리로 대규모 더미데이터를 빠르게 생성.

어떻게 포괄하는가

Python 폴더의 노트들은 네 축을 따라 Python 런타임이 만들어 내는 결정의 지형을 구성한다. 첫째, 비동기와 동시성 축은 Python에서 왜 그렇게 쓰지 못하는가라는 만성 질문을 다루며, python 코루틴(coroutine) - 동시성과 병렬성, 동기와 비동기 작업, blocking과 non-blocking 그리고 코루틴 (1)이 협동을 토대로 동시성·병렬성·blocking 개념을 한 자리에 묶고, MissingGreenlet — SQLAlchemy async에서 가장 흔한 함정이 그 토대 위에 ORM 비동기를 얹었을 때 가장 흔히 부서지는 자리를 명시해 이론과 실패 사례가 같은 페이지에 마주 보게 한다. 둘째, 웹과 네트워킹 축은 Python을 실제 서비스로 들어 올리는 표층 라이브러리들로, FastAPI를 위한 Elasticsearch 대안 — 검색 엔진 선택 가이드이 검색 엔진 선택이라는 통합 결정을, OPC UA Server·Websockets이 산업 프로토콜과 실시간 양방향이라는 프로토콜 다양성을 다루며 — 세 노트가 같이 놓이면 Python이 프로토콜 어댑터의 카탈로그로 작동함이 드러난다. 셋째, 언어 기본기와 내장 레퍼런스 축은 글로 풀어 쓴 코어 그대로를 책처럼 두는 영역으로, Unpacking이 destructuring이라는 일상적 관용구를, 파이썬 내장 오류 목록·파이썬 내장 함수 목록이 예외와 함수의 카탈로그를 둬 코드 작성 중 빠른 조회 표면을 만든다. 넷째, 데이터와 크롤링 축은 Python을 데이터 수집·생성의 일상 도구로 사용할 때의 패턴으로, 네이버 크롤링 난이도, 차단 방식, 해결법이 현실의 봇 차단에 대한 실무 적응을, 파이썬을 통한 대규모 더미데이터 생성 방법이 그 반대편 — 데이터를 만들어 내는 측의 패턴을 다뤄 수집·생성이라는 데이터 인풋의 양면을 한 폴더에서 본다. 네 축을 합쳐 보면 Python 폴더는 python 코루틴(coroutine) - 동시성과 병렬성, 동기와 비동기 작업, blocking과 non-blocking 그리고 코루틴 (1)이 토대로 깔리는 자리에서 언어 선택이 아니라 런타임 패턴 선택을 다루는 자리로 닫힌다.
