SQL

SQL

SQL 폴더는 문법·컨벤션, 쿼리 패턴과 데이터 모델링, 인덱싱·성능, 저장 프로시저·트리거의 네 축을 가로지르는 노트들을 모아 놓은 공간이다. SQL을 질의 언어 한 층이 아니라 언어·구조·성능·서버 측 로직의 네 층으로 나눠 본다는 점이 이 폴더의 시야다.

구성 개념

  • SQL Syntax 카탈로그 — join, subquery, CTE, window function, view를 색인한 카탈로그 허브. 항목 단위 진입점.
  • SQL Style Guide from Gitlab — GitLab의 SQL 스타일 가이드. 네이밍·포맷·주석 컨벤션 외부 레퍼런스.
  • 한국에서 가장 널리 쓰이는 sql convention을 찾아줘 - Genspark — 한국 현업에서 널리 쓰이는 SQL 컨벤션 정리.
  • temp_doc — 서브쿼리·CTE·상관 서브쿼리·EXISTS·GROUP BY·ROLLUP 실습 쿼리 임시 모음.
  • Snippets 모음 — INFORMATION_SCHEMA를 활용한 테이블·컬럼 구조 조회 등 실무 스니펫.
  • ERD 재귀 관계 — ERD 자기참조 재귀 관계(1:1, 1:N, M:N)와 WITH RECURSIVE 활용.
  • Indexing Strategies — 단일·복합·클러스터드 인덱스 유형과 인덱싱 전략, 성능 고려사항.
  • Bitwise Operation — MySQL 비트연산으로 다중 선택 항목을 효율적으로 저장·검색.
  • MySQL RAND 함수의 난수 생성 원리 — RAND() 내부 원리, 시드 동작, ORDER BY RAND() 성능 이슈.
  • Stored prodcedure — MariaDB 저장 프로시저·저장 함수의 생성/호출, IN/OUT 파라미터, 예외 처리.
  • SQL Procedure 사용 가능 함수 — 저장 프로시저 내 사용 가능한 SQL 함수와 GROUP BY/LIMIT 제한사항.
  • Trigger 예외 처리 방법 — MySQL 트리거에서 SIGNAL SQLSTATE로 INSERT/UPDATE/DELETE 예외 처리.
  • SQLSTATE 생성 가능 갯수 — SIGNAL SQLSTATE로 생성 가능한 사용자 정의 오류 코드(45000~45099) 범위.

어떻게 포괄하는가

SQL 폴더의 노트들은 네 축을 따라 질의 언어를 둘러싼 전체 지형을 구성한다. 첫째, 문법과 컨벤션 축은 같은 SQL이라도 어떻게 쓰는가의 규약을 다루며, SQL Syntax 카탈로그가 문법 항목을 색인하는 진입점을, SQL Style Guide from Gitlab·한국에서 가장 널리 쓰이는 sql convention을 찾아줘 - Genspark이 영어·한국어 두 시야의 컨벤션을 노출해 팀 컨벤션 결정의 비교 기준을 제공한다. 둘째, 쿼리 패턴과 데이터 모델링 축은 단순 SELECT를 넘어 재귀·집계·CTE·서브쿼리가 결합되는 자리로, temp_doc·Snippets 모음이 실전 패턴을 누적하고 ERD 재귀 관계이 데이터 모델 측면에서 같은 재귀 구조를 ER 표기로 끌어와 질의와 모델링이 같은 자리에서 만남을 보인다. 셋째, 인덱싱과 성능 축은 동일한 결과를 얼마나 빠르게 얻는가를 다루며, Indexing Strategies가 인덱스 자체의 설계 결정을, Bitwise Operation이 비트 표현이라는 대안적 효율화 패턴을, MySQL RAND 함수의 난수 생성 원리가 무해해 보이는 함수 한 줄이 전체 정렬 비용을 가져오는 함정을 명시해 성능 사고의 폭을 넓힌다. 넷째, 저장 프로시저와 트리거 축은 DB 안에서 돌아가는 로직이라는 다른 차원의 SQL을 다루며, Stored prodcedure·SQL Procedure 사용 가능 함수이 프로시저 정의와 그 안에서 가용한 함수 제약을, Trigger 예외 처리 방법·SQLSTATE 생성 가능 갯수이 트리거에서 오류를 어떻게 신호로 들어 올리는가라는 한 짝의 결정을 정리해 애플리케이션-측 로직과 DB-측 로직의 경계를 그린다. 네 축을 합쳐 보면 SQL 폴더는 SQL Syntax 카탈로그가 진입점을 잡는 자리에서 언어·구조·성능·DB-측 로직의 네 층을 동시에 다루는 카탈로그로 닫힌다.
