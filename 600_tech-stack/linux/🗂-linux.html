Linux

Linux

Linux 폴더는 셸 명령어·단축키, Bash 스크립트와 표준 입출력·정규표현식, 시스템 운영의 세 축을 가로지르는 노트들을 모아 놓은 공간이다. Linux를 OS 한 층으로 보는 대신 명령어 표면 → 스크립트 언어 → 시스템 도구가 같은 셸 위에서 굴러가는 작업 환경으로 본다.

구성 개념

  • Linux Commands — 파일·디렉토리 관리, 텍스트 처리, 프로세스, 권한, 네트워크, 압축 등 필수 명령어 카테고리별 정리.
  • Linux Hotkeys — GUI·터미널·TTY 전환·프로세스 관리 단축키 총정리.
  • Linux Shell built-in commands — Bash 내장 명령어(환경변수·디렉토리 스택·프로세스·리다이렉션)와 기본 쉘 스크립트 작성법.
  • Linux if문 공백에 관한 설명 — Bash if문에서 [ ]가 test 명령어 alias인 이유, 공백 필수성, [[ ]]과의 차이.
  • Linux 변수확장과 인용의 차이 — $변수와 "${변수}" 차이, 공백 포함 경로 인용 필요성, $() 명령어 치환 안전 사용.
  • Linux 표준입출력 — 와일드카드·리다이렉션(>/>>/<)·파이프·백그라운드·논리 연산자·변수 확장·이스케이프.
  • Linux 정규표현식 — Linux 정규표현식 기본 기호, grep·sed·awk 활용, 실전 예제(IP·이메일·로그).
  • Linux VM 만들기(feat.Virtual Box) — VirtualBox로 Linux VM 생성과 자원 할당 설치 과정.
  • tar 압축 방식(아카이브와 압축 차이) — tar 아카이빙과 gzip·bzip2·xz·zip 압축 차이, 형식별 특성·명령어 옵션.

어떻게 포괄하는가

Linux 폴더의 노트들은 세 축을 따라 셸 위의 작업 환경을 구성한다. 첫째, 명령어 표면 축은 입력 단위의 Linux를 다룬다. Linux Commands가 카테고리별 명령어 전수를 카탈로그화하고, Linux Hotkeys가 그 명령어를 입력하는 속도 자체를 끌어 올리는 단축키 표면을 더해 — 두 노트가 함께 놓이면 입력 효율이라는 하나의 결정으로 일반화된다. 둘째, Bash 스크립트와 표준 입출력 축은 명령어 한 줄에서 프로그래밍 언어로 넘어가는 자리를 다룬다. Linux Shell built-in commands가 내장 명령어를 정리하고, Linux if문 공백에 관한 설명·Linux 변수확장과 인용의 차이이 Bash 문법에서 가장 흔히 부서지는 두 함정(공백·인용)을 명시한다. Linux 표준입출력·Linux 정규표현식이 파이프·리다이렉션·정규표현식이라는 조합 단위를 더해 짧은 셸 한 줄로 일을 끝내는 패턴을 카탈로그화한다 — 이 다섯 노트가 폴더의 가장 두꺼운 축이다. 셋째, 시스템 도구 축은 셸 바깥의 시스템 운영 결정을 다룬다. Linux VM 만들기(feat.Virtual Box)이 격리 환경 자체를 만드는 방법을, tar 압축 방식(아카이브와 압축 차이)이 아카이빙과 압축이 서로 다른 일임을 분리해 — 두 노트가 폴더의 가장 얇은 축이지만 Linux를 실제 환경 위에서 사용하는 첫 진입점(가상화)과 그 결과를 보관·이동하는 마지막 단계(압축)를 모두 가진다는 점에서 폴더의 양 끝을 닫는다. 세 축을 합쳐 보면 Linux 폴더는 Linux Commands가 진입점을 잡는 자리에서 OS 카탈로그가 아니라 셸 위의 작업 환경 카탈로그로 닫힌다.
